# 得物商家入驻 · 智能填写演示

根据提供的入驻页截图还原页面，将品牌类目表单替换为内嵌智能填写区。采用原生 HTML、CSS、JavaScript，可直接通过 GitHub Pages 发布。

本地预览：在此目录运行 `python3 -m http.server 4173`，然后访问 `http://localhost:4173`。

支持本地 JPG/PNG 多图添加（单张不超过 100MiB）、拖拽、预览、移除、本地草稿和提交演示。图片只在浏览器内处理，不上传服务器；草稿仅保存文件信息，刷新后需重新选择图片。识别、审核、扫码和辅助功能均为演示，不连接得物业务系统。

页面使用得物公开静态品牌资源，商标证为重新绘制的脱敏虚构示例。本项目为页面方案演示，并非得物官方入驻服务。
